## 一、问题分析与总体方案（对应四.2.(1)）

### 1.1 问题理解

问题一要求基于附件1的100条原始视频，建立文本、语音、视觉三模态的
特征提取与时序对齐模型。题目对输出提出三项硬性要求：

| 题目要求 | 对应指标 |
|---|---|
| 原始样本覆盖完整性 | 样本编号、模态文件与输出特征一一对应 |
| 时序组织的可核验性 | 序列位置、有效长度、填充规则、与原始素材的对应记录 |
| 方法的合理性与可复现性 | 工具、关键参数、处理日志、复现说明 |

### 1.2 核心难点

三个模态的**时间尺度差异显著**：

| 模态 | 时间粒度 | 典型长度 | 说明 |
|---|---|---|---|
| 文本 | 词级 | 5 ~ 65 | 词数不定，无原生时间戳 |
| 语音 | 帧级 (100 Hz) | 226 ~ 2929 | 连续，有精确时间 |
| 视觉 | 帧级 (30 fps) | 67 ~ 875 | 连续，有精确时间 |

**关键矛盾**：文本没有时间信息，而语音和视觉有。因此**对齐的本质是
为文本词赋予时间区间**，再将语音和视觉按时间重叠聚合到该区间上。

### 1.3 总体流程

```
附件1 原始视频 (100条)
      │
      ├─► ffprobe 时间基准提取 ──────► manifest.jsonl
      │      (真实时长/帧数/逐帧PTS)
      │
      ├─► 音轨解码 (16 kHz 单声道)
      │      │
      │      ├─► 帧级能量分析
      │      └─► 约束式单调对齐 ──────► word_timelines.jsonl
      │             (逐词时间区间)
      │
      └─► 三模态特征接入
             │
             ├─► 按词区间时间聚合 ────► 50 位置对齐序列
             │      (帧中心落入 [start,end))
             │
             └─► 四类掩码 + 追溯记录 ──► alignment_trace.csv
                                       qc_report.csv
```

## 二、时间基准的确定（重要发现）

### 2.1 发现的问题

附件1 的 MP4 文件头部 `nb_frames` 字段**不可靠**。

**验证方法**：对同一文件分别用两种方式获取帧数

```python
# 方式A：读元数据（常用做法）
cap = cv2.VideoCapture(path)
n_declared = cap.get(cv2.CAP_PROP_FRAME_COUNT)   # → 261

# 方式B：逐帧解码计数
n_decoded = sum(1 for _ in frames)                # → 163
```

**验证结果（100条全量）**：

| 指标 | 数值 |
|---|---|
| 声明帧数与实际不符的样本 | **90 / 100（90%）** |
| 声明帧数合计 | 33,147 |
| 实际帧数合计 | 23,241 |
| 虚报帧数 | **9,906（29.9%）** |
| 时长比（声明/实际）最大 | **3.273** |
| 时长比（声明/实际）均值 | 1.528 |

### 2.2 影响

若采用 `帧数 ÷ 帧率` 计算时长：

```
样本 -9y-fZ3swSY$_$4
声明: 277 帧 ÷ 30 fps = 9.23 秒
实际:  81 帧 ÷ 30 fps = 2.82 秒     ← 偏差 227%
```

且**每条样本偏差比例不同**（1.0 ~ 3.27 倍），无法事后统一修正。

### 2.3 解决方案

本模型所有时间信息均取自 **ffprobe 解码结果**：

```python
# 容器真实时长
ffprobe -show_entries format=duration

# 逐帧真实时间戳
ffprobe -select_streams v:0 -show_entries frame=pts_time
```

对应实现：`src/q1_alignment/ffprobe_utils.py`

> **论文表述建议**：
> "经核查，附件1 的 100 条视频中有 90 条的容器元数据帧数字段与实际可解码
> 帧数不符，合计虚报 29.9%，据此计算的时长最大虚高 3.27 倍。为保证时序
> 组织的可核验性，本文所有时间信息均取自 ffprobe 的解码结果。"

## 三、约束式单调对齐模型（对应四.2.(1) 核心方法）

### 3.1 问题形式化

设某样本的转写文本含 `T` 个词 `w₁, w₂, …, w_T`，视频真实时长为 `D`。
求词边界

```
0 = b₀ < b₁ < … < b_T = D
```

使第 `t` 个词占据时间区间 `[b_{t-1}, b_t)`。

### 3.2 目标函数

```
minimize   Σ_{t=1}^{T}  w_t · ( (b_t − b_{t−1}) / ŝ_t − 1 )²
           −  λ · Σ_{t=1}^{T−1} P(b_t)
```

其中：

- **期望时长分配** `ŝ_t`

  ```
  ŝ_t = D · s_t / Σ_{k=1}^{T} s_k
  ```

  `s_t` 为词 `t` 的**发音权重**，由音节数估算：

  ```
  s_t = (元音组个数) × (功能词衰减系数)
  ```

  元音组计数比字符计数更贴近实际发音时长；对 the/a/of 等高频功能词
  施加 0.75 的衰减，因为它们在连续语流中通常弱读。

- **停顿奖励项** `P(·)`

  ```
  P(b) = ( E_median(Ω(b)) − E_min(Ω(b)) ) / E_median(Ω(b))
  ```

  `Ω(b)` 为 `b` 邻域 ±80 ms 内的能量集合。`P` 越大表示该处越接近
  声学静音，因而越适合作为词边界。

### 3.3 硬约束

| 约束 | 数学表达 | 作用 |
|---|---|---|
| 完整覆盖 | `b₀ = 0`, `b_T = D` | 保证不遗漏片段首尾 |
| 严格单调 | `b_t − b_{t−1} ≥ ε` | 保证无重叠、无零长度 |
| 语速合理 | `T/D ∈ [1, 6]` 词/秒 | 排除生理上不可能的分配 |

**这三条约束由构造保证**，而非事后检验。

### 3.4 求解

采用"初值构造 → 约束投影 → 停顿局部精化"三步：

1. **初值**：按期望时长累积分布给出 `b_t = D · Σ_{k≤t} ŝ_k / Σŝ`
2. **投影**：将边界投影到可行域（顺序前推 + 逆序回拉），保证硬约束
3. **精化**：对每个内部边界，在 ±80 ms 内寻找能量谷 `b*`，
   按 `b ← α b* + (1−α) b` 移动（`α = 0.5`），随后重新投影

### 3.5 为什么必须用约束式（方法动机）

**初版实现采用"按有声段独立分配词"的启发式**：先用能量阈值切出有声段，
再在每个段内按比例分配词。该实现存在**系统性缺陷**：

当有声段多而词数相对少时，**早期段消耗完全部词，后续段分到 0 个词被跳过**。

| 样本 | 真实时长 | 词数 | 初版末词结束 | 初版覆盖率 | 初版等效语速 |
|---|---|---|---|---|---|
| `-iRBcNs9oI8$_$9` | 3.416 s | 5 | 0.258 s | 7.54% | **19.4 词/秒** |
| `-yRb-Jum7EQ$_$5` | 13.169 s | 25 | 1.718 s | 13.04% | **14.6 词/秒** |
| `-yRb-Jum7EQ$_$1` | 29.288 s | 49 | 7.117 s | 24.30% | 6.9 词/秒 |

"19.4 词/秒"在生理上不可能，说明该结果无效。

**关键教训**：该缺陷**通过了全部结构性校验**（时间单调、数值有限、
落在时长范围内），却完全错误。这说明**仅依赖结构校验不足以保证
对齐正确**，必须引入覆盖率与语速约束。这正是本文改用约束式建模的直接动因。

## 五、四类掩码的设计（对应"时序可核验性"）

| 掩码 | 含义 | 取值说明 |
|---|---|---|
| `sequence_mask` | 是否属于真实序列位置 | 含 `[CLS]`、内容位、`[SEP]`；padding 位为 0 |
| `text_mask` | 文本在该位置是否有有效特征 | 词组内无词时为 0 |
| `audio_mask` | 音频在该位置是否有有效帧 | 空区间时为 0 |
| `vision_mask` | 视觉在该位置是否有有效帧 | 空区间时为 0 |

**额外输出** `vision_valid_ratio` —— 该位置内源级视觉有效帧的占比。

> **设计意图**：题目要求区分"Padding"、"模态无数据"和"人脸检测失败"。
> 三者数值上都可能表现为 0，仅靠数值无法区分，因此必须用独立掩码标记。
> 其中 `vision_valid_ratio = 0` 表示该区间内**没有人脸被检出**，
> 而 `vision_mask = 0` 表示该区间**根本没有视觉帧**——两者语义不同。

## 六、序列位置的整理规则

统一序列长度 `L = 50`：

```
位置 0        : [CLS]
位置 1..48    : 内容位（最多 48）
位置 49       : [SEP]
```

**词到位置的映射**：

- 词数 `T ≤ 48`：每词占一个位置
- 词数 `T > 48`：按顺序均匀合并为 48 组，**覆盖完整文本**
  （使用 `numpy.array_split`，避免直接丢弃末尾内容）

**实测**：100 条样本中仅 **2 条**词数超过 48（最多 65 词），
其余 98 条为逐词对应。

## 九、创新点小结

1. **约束式单调对齐模型**：将对齐形式化为带硬约束的优化问题，
   覆盖率、单调性、语速合理性由构造保证，而非事后检验
   （覆盖率 41.4% → 100%，98 条可发声样本）

2. **停顿感知的边界精化**：利用声学能量谷引导词边界，
   边界能量降低 21.95%（40/40 样本改善）

3. **音节感知的时长权重**：以元音组估算发音权重而非字符数，
   并对功能词施加弱读衰减

4. **四级可核验 QC**：在常规结构校验之外，增加覆盖率与语速
   两项语义校验，正对初版方法的失败模式

> 创新点 2 用消融实验支撑；创新点 3 简要说明即可。
> 所有创新点均建立在**自我修正**的方法论之上，这本身可作为
> 论文"严谨性"的加分论述。
