# E题 问题一：三模态情感特征提取与时序对齐（方法代码）

2026 年中国研究生数学建模竞赛 E 题《复杂场景下多模态情感预测的数学建模与算法设计》问题一的实现代码。
数据来源**仅**为赛题附件1（100 条原始视频与 `label-100.xlsx`），未引入任何外部情感数据集。

## 目录结构

```
src/q1_alignment/          问题一实现（提取接口适配 → 词级时间分配 → 帧-词聚合 → 50 位置序列与掩码）
scripts/run_q1_pipeline.sh 8 步全流程入口（含每步校验）
config.yaml                对齐侧冻结配置
versions.txt  requirements.txt  版本与环境
docs/                      方案说明、交付接口规格、提交材料说明
handoff/q1_expected_words.csv   公布的规范词轴（供特征提取方对账）
```

## 方法要点

1. **主时间轴**：`D = max(容器声明时长, 视频轨, 音频轨, 逐帧显示时间戳末帧 + 一个帧周期)`（四项逐样本落盘，不做无校验的元数据替换）。
2. **词级时间分配**：期望时长由元音组计数与功能词弱读系数 0.75 决定，`ŝₖ = w_k/Σw·D`；
   可行域为完整覆盖 + 严格单调（每段不短于 `min(20 ms, D/T)`）；语速带 [1,6] 词/秒为**样本准入判据**而非可行域；
   求解按「累积初值 → 前推回拉投影 → ±80 ms 能量谷吸附 → 再投影」四步执行，属**启发式**，不声称最优。
   该方法为**词级近似时间分配**，不含词/音素声学匹配项。
3. **帧-词聚合主规则**：位置 k 的入选源帧集合 `R_k = { r : c_r ∈ J_k 且 q_r = 1 }`，
   仅当集合非空时取等权均值并置观测掩码为 1；音频帧时间中心取 25 ms 分析窗中点，视觉帧取该帧 PTS；
   视觉检测置信度只记录、不参与筛选。另附按重叠时长加权的对照口径。
4. **位置轴**：0 号为起止标记、1..n 为内容位（`n = min(词数, 48)`）、其后为填充、第 n+1 位为结束标记；
   存储长度固定 50，并显式记录内容位数 `L_content` 与有效长度 `L_valid = L_content + 2`。
   词数超过 48 时按词序等分为 48 组，逐位置保存覆盖的原词下标区间。
5. **静音准入**：整条音轨峰值低于 `1×10⁻⁵` 时不进入边界求解，词级时间填 `−1.0` 哨兵并标记 `audio_absent`；
   文本通道仍按词索引分组有效，样本保留在交付清单内。

## 运行

```bash
export MOSEI_ROOT=/path/to/project
export PYTHONPATH=$MOSEI_ROOT/src
pip install -r requirements.txt
bash scripts/run_q1_pipeline.sh            # 8 步全流程；每步写产物并校验
python -m q1_alignment.diagnose_align      # 逐样本求解诊断（目标值/约束残差/失败分支）
```
