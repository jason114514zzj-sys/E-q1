## 四、跨模态时序对齐规则

1. **主时间轴**：右端取「容器声明时长、视频轨时长、音频轨时长、末帧时间戳 + 一个帧周期」四者的最大值；四项在逐样本清单中并列保存，不做无校验的元数据替换。帧时间取自 ffprobe 逐帧显示时间戳，不用帧号除以帧率的估计值。
2. **词级边界**：以转写文本与音频为输入，最小化按期望时长（由元音组计数与功能词弱读系数 0.75 决定）归一化的时长偏差平方和，并对低能量位置给予奖励；可行域由完整覆盖与严格单调（每段不短于 min(20 ms, D/T)）两项硬约束给出；语速带 [1, 6] 词/秒作为**准入判据**而非可行域约束。求解按「累积初值 → 前推回拉投影 → ±80 ms 能量谷吸附 → 再投影」四步执行，属启发式求解，不声称全局最优。该方法属**词级近似时间分配**，不含词或音素的声学匹配项（见第九节限制）。
3. **位置轴**：0 号位为起止标记、1..n 为内容位（n = min(词数, 48)）、其后为填充位、第 n+1 位为结束标记；存储长度固定 50，并显式给出内容位数 `L_content`、有效长度 `L_valid = L_content + 2`。
4. **聚合主规则**：位置 k 的入选源帧集合为「时间中心落入该位置词区间且源级可信标记为 1」的帧集合，非空时取等权均值并把该位置观测掩码置 1。音频帧的时间中心取 25 ms 分析窗中点，视觉帧取该帧 PTS；检测置信度只记录、不参与筛选。另附按重叠时长加权的对照口径及其逐位置差异表。
5. **超过 48 词**：按词序等分为 48 组连续词组；文本取组内词向量等权平均，音频与视觉用该组整体时间区间直接从源帧重新聚合；逐位置保存覆盖的原词下标区间。
6. **静音准入**：整条音轨峰值低于 1×10⁻⁵ 时不进入边界求解，词级时间填 −1.0 哨兵并标记 `audio_absent`；文本通道仍按词索引分组有效，音视频掩码全置 0，样本保留在交付清单内。

## 五、文件结构与读取方式

```
features/aligned_50/<safe_id>.npz    对齐后的 50 位置三模态特征与掩码
features/aligned_50/<safe_id>.json   逐位置溯源（原词、时间区间、源帧索引）
results/                             全量汇总、逐位置追溯、质量与有效性清单
examples/                            典型样本验证材料
code/                                实现与测试
config/                              配置、版本、依赖、列语义
logs/                                完整运行日志
```

`<safe_id>` 为 `video_id__clip_id`（原 `video_id` 与 `clip_id` 之间以两个下划线连接），与附件1 的目录/文件一一对应；100 条样本全覆盖。

**npz 键**：`text (50,768) float32`、`audio (50,58) float32`、`vision (50,49) float32`、`sequence_mask`、`attention_mask`、`text_mask`、`audio_mask`、`vision_mask`（各 `(50,) uint8`）、`vision_valid_ratio (50,) float32`、`interval_start`/`interval_end (50,) float32`、`effective_length`、`original_word_count`、`original_audio_length`、`original_vision_length`（标量）。

**json 字段**：`id`、`safe_id`、`timeline_method`、`alignment_method`、`timeline_final_usable`、`audio_absent`、`text_word_coverage`、`max_positions`、`content_positions`、`effective_length`、`long_text_grouped`，以及 `bins` 列表——每个位置含 `position`、`word_start_index`、`word_end_index`、`text`（该位置覆盖的原词）、`start`、`end`、`text_feature_indices`、`audio_feature_indices`、`vision_feature_indices`（源数组下标集合）。

**读取约定**：掩码为 0 的位置时间字段为 −1.0 哨兵；掩码为 1 的位置其时间与源帧索引可以按上述规则从原始帧级数组复算。

## 六、工具、版本与运行流程

| 环节 | 工具与版本 |
|---|---|
| 媒体解析 | ffmpeg / ffprobe 7.1（`format.duration`、逐帧 `best_effort_timestamp_time`、解码帧数） |
| 音频解码 | ffmpeg 7.1，16 kHz 单声道 float32 |
| 文本编码 | transformers + 本地 `bert-base-uncased` 权重；实现含自建 WordPiece 重建与逐位核对 |
| 视觉特征 | OpenFace 2.0（由特征提取模块产出，配置见 `config/handoff_config_v1.0-frozen.yaml`） |
| 数值计算 | Python 3.10.21、NumPy 2.2.6、SciPy 1.15.3 |

**运行流程**（8 步）：① 读取附件1 清单并建立媒体清单（四上界）；② 解码音频并计算帧能量；③ 转写分词与词级边界求解；④ 静音准入判定；⑤ 按帧中心落入区间聚合三模态；⑥ 文本按子词到原词映射分组；⑦ 整理 50 位置与四类掩码；⑧ 输出逐位置时间、可用性标记与源帧追溯。

## 九、已知限制（如实标注）

1. 词级边界由期望时长先验与能量谷吸附共同确定，属**近似时间分配**，不含声学词匹配；覆盖率与语速在词数和时长给定后由构造决定，是结构性指标，不能作为边界与实际发音对应正确的证据。
2. 式（4-12）的平均边界绝对误差需要人工核验参照边界，本包不给出该指标的估计值。
3. 视觉帧数一致性检查只核实两个数组长度相同，是帧轴正确对应的必要条件而非充分条件；逐帧顺序由逐位置源帧索引追溯核验。
4. 语速带 [1, 6] 词/秒为样本级准入判据，不约束逐词跨度，故逐词瞬时语速（段长倒数）可以超带：本批 63 条样本出现该情形（单条最多 10 个词），逐样本计数见 `results/alignment_diagnostics.csv`。
5. 音频与视觉的片段级重要性在本包中不作结论：问题一交付的是特征与对齐，模态作用与片段定位在问题三中给出。
